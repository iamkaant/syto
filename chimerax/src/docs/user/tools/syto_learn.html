Tool: Hit Picking Learn

Hit Picking Learn is the active-learning panel of the Syto bundle. You grade some poses, a small model learns from your grades, and it tells you which poses are worth looking at next. It is a port of AutoParty and is optional: nothing is loaded until you use it. See also: Hit Picking Handbook, ViewDock, hitpick learn

Open it from Tools → Binding Analysis → Hit Picking Learn or with hitpick learn panel. The receptor and poses must be open and hitpick setup run first.

[back to top]

The loop

  1. Analyse poses (hitpick learn collect) computes the features of every pose. It runs in the background; the panel shows progress and Cancel stops it.
  2. Grade some poses bad, maybe or good, with the large buttons in the panel or with ViewDock's own rating (keys b, m, g). Grades are stored in ViewDock's Rating column, so your opinion is recorded in one place only.
  3. Train (hitpick learn train) fits a committee of small neural networks to the grades given so far. The training curve is shown in the panel.
  4. Look at these next lists the poses to grade now. Click a row to jump to that pose. Grade them, train again, and repeat.

By default, grading a pose moves straight on to the next suggestion.

Choosing what to look at next

StrategyShows you
uncertaintyposes the model is least sure about; grading these teaches it most (the default)
disagreementgraded poses where the model disagrees with your grade
predictionthe poses it predicts are best

The work-list button puts the suggestions into the ViewDock table in the model's order (hitpick learn worklist). A pose leaves the list when you grade it, so b/m/g walks the batch. The list is not re-ranked while you work it.

hitpick learn apply writes the model's predictions into the ViewDock table as sortable columns.

Docking score terms

The model learns from the interaction fingerprint, ligand features and, optionally, up to seven of the docking program's own score terms. For DOCK 3 mol2 files the terms are recognised automatically. For other programs choose them in the Docking score terms section (Apply, Auto, None); identifiers such as rank or pose number are marked as unusable so they cannot leak into the model.

[back to top]

Rating by exception

If you went through a whole list and only marked the poses you objected to, the model has no examples of what you would buy. The panel then offers to treat the unrated poses as good (hitpick learn assume). Use this only on a list you walked to the end: on a half-finished list it labels poses you never looked at. The assumed grades are kept apart from the ones you gave and can be removed with hitpick learn assume forget true.

[back to top]

Saving

Save… and Load… write and read one JSON file holding the grades and the trained model (hitpick learn save, hitpick learn load). The panel is not saved in ChimeraX sessions.
